# ZAVIK desktop app

Download the ZAVIK app for **Windows** and **Mac** from **https://www.zavik.in/download**.

The app opens ZAVIK in its own window and always shows the latest version, so there is nothing to update by hand.

The files themselves are attached to the [latest release](../../releases/latest):

| File | For |
|---|---|
| `ZAVIK-windows-setup.exe` | Windows 10 or 11 (installer) |
| `ZAVIK-windows-portable.zip` | Windows, unzip and run |
| `ZAVIK-mac-apple-silicon.dmg` | Macs with an M1, M2, M3 or M4 chip |
| `ZAVIK-mac-intel.dmg` | Macs with an Intel processor |

These builds are not yet code-signed, so Windows may show "Windows protected your PC" (click **More info**, then **Run anyway**) and macOS may ask you to right-click the app and choose **Open** the first time.
